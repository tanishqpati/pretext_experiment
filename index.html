Resize Comparison

    

      Drag the corner of the box to resize it. On each resize event, two timings are measured:
      layout() (Pretext — pure arithmetic, no DOM) vs a hidden off-screen
      element's getBoundingClientRect() at the same width — both measuring
      the same text at the same width for a fair comparison.

  const { height } = layout(handle, width, lineHeight); // <0.1ms
